# Licenses for generated data

These files are pulled from open datasets by `scripts/pull-sources.mjs`. Each keeps its source's license. Every item also has a `source` field naming where it came from.

| File | Source | License |
| --- | --- | --- |
| `text.json` | World English Bible | Public domain |
| `places.json` | OpenBible.info Bible Geocoding Data | CC BY 4.0; outlines marked `osm` are © OpenStreetMap contributors, ODbL 1.0 |
| `people.json` | Theographic Bible Metadata | **CC BY-SA 4.0** (adapted: filtered to Ruth, reshaped, dates and dictionary text removed) |
| `words.json` | STEPBible Data, Tyndale House Cambridge | CC BY 4.0 |
| `crossrefs.json` | OpenBible.info Cross References | CC BY |

`people.json` is an adapted version of a share-alike dataset, so it is published here under CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/). If you reuse it, keep that license and credit Theographic Bible Metadata (https://github.com/robertrouse/theographic-bible-metadata).
